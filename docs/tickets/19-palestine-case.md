## 내용

- 원문: `docs/asset/비상플리마켓_팔레스타인큐알_1009.pdf`
- 식민지역사박물관의 각 전시 구역에 QR을 붙인다. 문제는 팔레스타인 내용이다.
- 단계
  - INTRO: 식민지역사박물관 × 팔레스타인 — 다섯 개의 질문 소개
  - QR 01~05: 제목 = 전시 구역(예: `01. 1부 「일제는 왜 한반도를 침략했을까」`),
    본문 = 소제목 질문, 문제 + ①②③ SINGLE_CHOICE, 해설 = 공개 텍스트,
    공개 이미지 = `docs/asset/Q1~Q5`
  - FINAL: 보너스 질문 06 (책방79-1 부스)
  - CLOSING: 다섯 문제의 키워드
- 상태는 DRAFT로 만든다 — 사용자가 확인 후 LIVE로 바꾼다.
- 테마 "팔레스타인"은 틀만 만든다. 이미지·색·폰트는 사용자가 고른다.
- 자격증명은 `docs/asset/.secret`(git ignore)에서 읽고 로그·커밋에 남기지 않는다.
