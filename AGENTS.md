## rule

1. keep code simple and understandable.
2. thinking in multiple hat. user's hat, developer's hat, designer's hat, tester's hat

## loop

1. plan and design, research it.

2. turn a item from `PLAN.md` into automated test that fail (RED)

3. implement it correctly.

4. run typecheck, test, lint, format. make them pass. commit it. (GREEN)

5. review the code. refactor it. update and add new cases to `PLAN.md`. don't forget to commit it. (REFACTOR)

6. GO to 1.
